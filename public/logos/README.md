# Logo slots

Drop the **official** logo files here (SVG preferred) using exactly these names:

| File                | Organization                          |
| ------------------- | ------------------------------------- |
| `hacktoberfest.svg` | Hacktoberfest                         |
| `cnsp.svg`          | Cloud Native Security Pakistan        |
| `mlh.svg`           | Major League Hacking (MLH)            |

If a file is missing, the app renders a plain-text wordmark with the organization name instead.
No logos are bundled in this repository on purpose — only use authorized brand assets.
